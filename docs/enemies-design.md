# M2-B — 敵人基底設計（5 種 × 模組化配件）

## 設計原則
- 基底 = 骨架 + 動作集 + 元素屬性的最小單位
- 視覺變化 = 染色 × 配件 × 武器 × 光環 × 體型 → 由 AI 隨機組合
- 全部敵人與黎恩同風格：日系寫實 7–8 頭身，Low-Poly 起手

## 五種基底

| ID | 名稱 | 體型 | 守護元素 | 動作風格 | 代表武器 |
|----|------|------|----------|----------|----------|
| E1 | 掠焰狼 Ember Prowler | 瘦長狼形人（7.5H） | 火 | 突進 + 火焰斬擊（連續二刀） | 火焰彎刀 |
| E2 | 巨石守衛 Stoneguard | 壯碩岩石巨人（8H） | 地/無 | 格擋 + 重拳 + 震地 | 石盾（背負）+ 石拳 |
| E3 | 火語術士 Embermancer | 法袍人形（7.5H） | 火 | 詠唱 + 火彈 + 範圍灼燒 | 法杖 |
| E4 | 冰霜射手 Frost Archer | 弓手人形（7.5H） | 冰 | 後跳 + 冰矢 + 減速陷阱 | 長弓 |
| E5 | 雷角巨獸 Stormhorn | 四足獸型（體長 ~ 1.5H×5） | 雷 | 衝撞 + 踐踏 + 雷吼 AoE | 天生雷角 |

## 模組化配件（每種基底 3–5 個插槽）
| 插槽 | 配件選項 |
|------|----------|
| 頭部 | 角 ×4 / 獠牙 ×3 / 面具 ×4 |
| 背脊 | 翼 ×3 / 棘 ×3 / 旗 ×2 |
| 武器 | E1 武器 ×4 / E2 巨盾花紋 ×3 ... |
| 光環 | 火紅 / 冰藍 / 雷紫 / 無 |
| 體型 | 瘦弱 / 標準 / 壯碩 ×3 |

每種基底可產生 **> 4×3×4×4×3 = 576 種外觀**。

## 染色策略
- 每種基底提供 4 種主材質染色（PBR 可重用）
- 光環粒子跟隨「守護元素」自動配色
