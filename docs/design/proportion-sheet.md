# 黎恩 — 比例規格與三視圖文字規格

## 1. 頭身比例（7.5 頭身）

- 身高設 178 cm ⇒ 頭高 H = 178 / 7.5 ≈ **23.7 cm**
- 各部位以「H」為單位（自頭頂起算）：

| 區段 | 起點 | 終點 | 備註 |
|------|------|------|------|
| 頭部 | 0H | 1H | 下巴為 1H |
| 頸+肩 | 1H | 1.5H | 肩線 |
| 胸 | 1.5H | 2.2H | 乳線約 1.8H |
| 腰 | 2.2H | 2.7H | 腰最細處 |
| 骨盆 | 2.7H | 3.7H | 胯部 3.5H |
| 大腿 | 3.7H | 5.2H | 膝蓋約 5H |
| 小腿 | 5.2H | 6.9H | 腳踝 6.9H |
| 足 | 6.9H | 7.5H | 貼地 |

寬度指引：肩寬 ≈ 2.0H；腰寬 ≈ 1.2H；臀寬 ≈ 1.5H；臂長（肩→指尖）≈ 3.2H。

## 2. 三視圖建模規格（給建模師 / AI 生圖 prompt 用）

### 正面（Front）
- 站姿：A-Pose，雙腳與肩同寬，雙臂微張 30°
- 頭部：及頸深藍黑中長髮，瀏海分三束挑染電光白一撮；左眼琥珀金右眼冰藍
- 服裝：高領緊身衣 + 深灰胸甲 + 暴風灰藍長風衣敞開 + 深灰長褲 + 戰鬥靴
- 配件：左肩單片輕甲、右手纏繃帶、左耳耳墜、腰後懸劍鞘

### 側面（Side）
- 頭部：髮尾過頸線 3 cm，後腦自然層次
- 軀幹：胸甲前凸弧度克制，腰部自然內收，脊線微弓
- 風衣：前短後長，後下襬及膝，垂墜感明確
- 劍鞘：自腰後右側斜向下方延伸 25°，長度及膝上

### 背面（Back）
- 髮：中長髮自然垂落肩胛上緣，髮尾挑染白
- 風衣：背中線開衩至腰部，方便腿部動作
- 劍鞘：在腰後呈 25° 斜角，可見磁吸扣細節
- 右肩披風扣環為金屬圓環 + 三段布帶
