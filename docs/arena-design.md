# M2-A — 競技場場景設計（元素競技場 Arena of Elements）

## 1. 設計目標
單一**封閉圓形戰鬥場地**，用於 MVP 驗證核心戰鬥。風格需與黎恩的「日系寫實 7.5 頭身、風暴 + 三相元素」調性一致；不追求 AAA 細節，但必須在網頁 WebGL 上流暢運行。

## 2. 場景核心概念 — 「三相遺跡」
廢棄的古代元素研究場，中央是曾經封印「三相之核」的圓形儀式場。現在已殘破，成為流浪者試煉與傭兵比鬥的場所。

關鍵詞：**暴風天空 / 浮空石島 / 雷紋石柱 / 元素裂痕 / 圓形競技場**

## 3. 平面配置（Top-Down）

```
              [北 · 入場石門]
                    ∧
       (西 · 觀眾殘台) ════════╗
                    ║   ★     ║═══════ (東 · 浮空看台)
                     ║ 戰鬥圈  ║
                    ║ 直徑 30m ║
       (西南 · 元素裂隙) ═════╝
                    V
              [南 · 觀景崖緣]
```

- **戰鬥圈**：直徑 30 m 的圓形石質場地，外圈有雷紋石柱（8 根，高 6 m，提供掩體）
- **地面**：深灰石板 + 三道元素裂痕（火紅 / 冰藍 / 雷紫），戰鬥中會對應元素反應發光
- **觀眾殘台**：西側浮空看台，可看到遠處暴風雲海（Skybox 敘事）
- **觀景崖緣**：南側突出的一段斷崖，用於劇情演出與拍照模式
- **入場石門**：北側，高 8 m 的殘破石門，作為玩家出場點

## 4. 光照與天空
| 項目 | 設定 |
|------|------|
| 時刻 | 暴風黃昏（Golden Hour + Storm Clouds） |
| 主光 | 暖金色的側逆光（從西南斜過，營造長影） |
| 補光 | 暴風雲本身的冷藍反光，填亮陰影 |
| 元素裂光 | 地面三條裂縫，戰鬥時對應元素發光（火紅/冰藍/雷紫） |
| 遠景 | 閃電雲柱在天際線偶爾閃爍，提供動態天空 |

## 5. 美術資產清單（Low-Poly 起步）
| 類別 | 資產 | 多邊形預算 | 備註 |
|------|------|------------|------|
| 地面 | 圓形石質場 1 塊 + 裂縫貼圖 3 張 | <5K | 1 張 2K PBR 貼圖 + Emission |
| 石柱 | 雷紋石柱 8 根（3 種變體共用） | 各 <1.5K | 模組化 |
| 石門 | 殘破石門 1 座 | <4K | 破損邊緣用 Normal map |
| 看台 | 西/東浮空看台 2 座 | 各 <3K | 遠景可簡化 |
| 崖緣 | 觀景崖緣斷壁 1 座 | <2K | 用於拍照模式 |
| 天空 | Skybox HDRI + 閃電雲 Particle | - | 動態天象 |
| 燈光 | Directional Light + 裂縫 Emission | - | 烘焙 Lightmap |

**總面數上限**：場景 < 30K（手機 WebGL 穩定 60fps）

## 6. 性能預算（Web 優先）
- 三角面：< 200K drawn / frame
- 貼圖記憶體：< 128 MB（壓縮為 ASTC）
- 動態光：僅 1 盞 Directional + Emission 材質
- 粒子：僅 裂縫 Glow + 閃電遠景 2 種
- 物理：無動態破壞，僅劍氣 Trail 視覺效果

## 7. 與戰鬥系統的連動
| 元素 | 場地反應 |
|------|----------|
| 火 | 地面裂縫泛紅光，石柱燃燒起來 |
| 冰 | 地面裂縫泛冰藍，霧面材質覆蓋地面 30 秒 |
| 雷 | 列柱頂端閃電連線，地面出現雷網殘影 |
| 超導（冰+雷） | 中央裂縫炸開小範圍碎裂視覺 + 範圍 buff 區域 |

## 8. 後續擴充的插槽
- 大廳（角色換裝 / 抽卡）
- 章節地圖（開放世界的第一片群島）
- 多人競技（PVP 模式）

## 9. 驗收標準
1. 場景在 Unity URP 移動端設定下可跑 **60fps** （720p WebGL）
2. 暴風雲 + 暖金側光 + 三道元素裂縫同框可見
3. 玩家可在 30m 圓形場內繞圈無卡頓，石柱不擋視線
