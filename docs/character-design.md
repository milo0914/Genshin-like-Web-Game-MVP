# 主角設定稿 — 「嵐刃・黎恩（Rein）」

## 1. 設計定位

一句話：**「駕馭三元素的流浪劍士，在競技場中尋找自己的過去。」**

為 MVP「元素競技場」而生。三元素（火/冰/雷）集於一把可變形之劍，讓玩家在原型階段就能完整體驗元素反應玩法，不必解鎖多位角色。

## 2. 基本資料

| 項目 | 設定 |
|------|------|
| 姓名 | 黎恩（Rein）/ 稱號「嵐刃」 |
| 性別/年齡 | 男性，外貌約 22 歲 |
| 身高 | 178 cm（7.5 頭身，頭長約 23.7 cm） |
| 體態 | 精瘦結實，肩寬適中，動作靈敏 |
| 髮型 | 及頸中長髮，深藍黑髮帶一撮挑染的電光白 |
| 眼眸 | 左眼琥珀金、右眼冰藍（異色瞳，暗示體內三元素衝突） |
| 聲線 | 冷靜寡言，戰鬥時爆發力強 |

## 3. 背景故事（MVP 只需 200 字級別）

黎恩是一名在各地競技場流浪的傭兵劍士。三年前在一場暴風雨中被「三相之核」
擊中，體內因此寄宿著火、冰、雷三種互不相容的元素之力。為了不讓力量失控，
他刻意封印記憶，以競技場的實戰不斷錘鍊自己。每次戰鬥結束，他劍上的裂痕就
會加深一分——直到真相現形的那一天。

## 4. 元素與武器

### 武器：三相之劍「裂空」（v2 — 以圖片為基礎 + 設定稿細節）
- **型態**：單手長劍（沿用設定稿，非圖片的雙手大劍）
- **外觀**：**劍刃造型與主視覺圖一致**（銀白劍身 + 金色十字劍格 + 深色纏柄），但 **劍格中央嵌有三枚碎晶（赤 / 藍 / 紫）**，為「三相之核」碎片
- **三元素型態**：
  - **炎型態**：劍刃三段泛赤紅熔紋（對應赤晶亮起）
  - **霜型態**：劍刃覆冰晶紋路（對應藍晶亮起）
  - **雷型態**：劍刃纏繞紫電（對應紫晶亮起）

### 右手（沿用設定稿）
- 右手**纏繞繃帶**（封印雷元素暴走）——此為角色核心標誌，**主視覺圖未呈現，但做為正式設定**
- 左手沿用圖片皮革長手套

### 元素反應（MVP 範圍）
| 組合 | 反應 | 效果 |
|------|------|------|
| 火 + 冰 | 融穿 | 高額爆發傷害 |
| 火 + 雷 | 過載 | 範圍爆破 + 擊退 |
| 冰 + 雷 | 超導 | 範圍破甲，降低物防 |

## 5. 服裝系統（由內而外）

1. **貼身層**：黑色立領機能緊身衣，胸側有三條細紋（赤/藍/紫）隨元素活化發光
2. **中層**：深灰色短打護胸甲，左肩單片輕甲，右肩披風扣環
3. **外套**：及膝立領長風衣，主色「暴風灰藍」，內襯深紫，右袖口有雷紋刺繡
4. **下裝**：深灰貼腿長褲，膝部有機械護具
5. **足部**：及踝戰鬥靴，金屬鞋頭
6. **配件**：
   - 左耳單邊電光石耳墜
   - 右手纏繞繃帶（封印雷元素暴走）
   - 腰後掛劍鞘，磁吸式

## 6. 性格與表演關鍵詞

冷靜 / 寡言 / 內在暴烈 / 守護者 / 自我放逐
- 待機：微微低頭、右手撫劍柄
- 勝利：拋劍入鞘，轉身離場
- 受傷：左手按住右眼（冰元素暴走前兆）

## 7. 與系統的連動

- 4 人隊伍切換骨架中，黎恩是「Driver」（主驅動位），其他 3 位為協同元素釋放位
- 抽卡/外觀系統可擴充：換色皮膚 = 風衣與髮色替換，不改骨架
